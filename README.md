# new-swati

 Spend Summary – Flutter App

A responsive Flutter application that displays monthly spending, category-wise expenses, and a list of recent transactions.  
It supports **light/dark mode**, **responsive layouts** (mobile/tablet/desktop), and uses **hardcoded mock data** – no backend required.

##  Features

-  **Header Card** – shows total monthly spend with percentage change vs last month  
-  **Horizontal Category Scroll** – Food, Travel, Shopping, etc. with icons and amounts  
-  **Recent Transactions List** – 57 mock transactions with dates and category chips  
-  **Floating Action Button** – to add a new transaction (shows a snackbar)  
-  **Dark / Light Mode** – automatically follows system theme  
-  **Responsive UI** – mobile (column) and tablet/desktop (two‑column) layouts  

##  Tech Stack

- Flutter (Dart)  
- Google Fonts (Inter font)  
- Material 3 design
